# 「Science of AI 最小闭环」现象的理论解释

> 日期：2026-10-21 ｜ 对象：`../../Science of AI 最小闭环/Science of AI 最小闭环.md` 里的实验观察
> 定位：与 `kb-explained.md`（KB 经验律）平行的现象解释——这边是"解题器/元学习"层面的观察。
> 每条标注：已解释 / 部分解释 / 不在本理论范围。

---

## 1. 王泽浩的「等价算力 / 截断训练基线」

**现象**：每个候选只训预算的 ρ 倍、选当前领先者。v1.5 main 500 题：ρ=10% → 79.4%，ρ=30% → ~90%；DataFlip：ρ=10% → 44–53%，ρ=75% 才 ~90%。最强 LLM 的知识只相当于 7–8.5% 的试探训练。

**理论解释（已解释，且有独立复算）**：

- 主线题的排序**早定**：在核/lazy 图像里，候选差距主要由"可学窗口 $\eta\lambda_jT$ 内谁学得多"决定，大 $\lambda$ 方向先学、差距先拉开；排名稳定时间 ≪ 预算。所以 10% 截断就接近终局。
- DataFlip 题是**特意选出的"曲线交叉"题**（strict gate：同一组候选在两个数据集变体上赢家翻转）。交叉点天然在预算后段 → 早截断回到 ~50%（三选一里两可）。
- **我们的答题器独立复现了这条截断曲线**（不训练真实网络，只读惰性替身在预算分数 ρ 处的指标）：dataflip 上 39%@5% → 49%@65% 之后平台（`../verification/dataflip_result.md` §3），与实测基线同水平、同形状。这不是拟合——答题器在 dataflip 上是零拟合真 OOS。
- "LLM 知识 ≈ 7–8.5% 试探训练"的读法：LLM/KB 编码的是**早期可得的平均信号**（架构/lr 的典型方向），而早期信号本来就值 79%；知识超不过早期信号，因为 KB 没编码有限 $T$ 动力学的后期交叉。

**可证伪预测**（P-CL1）：在任意新题集上，"截断准确率曲线"应由初始化核谱 + 预算算出；曲线在 ρ 小的位置就平台的题集，KB 价值低；交叉题密度高的题集，KB/理论价值高。

## 2. 翻转题上 LLM 全部 41–53%（≈随机+）

**现象**：10% 截断时领先但最终输的 ~103 道翻转题上，所有参评 LLM 只有 41–53%。

**解释（已解释）**：与 §1 同一枚硬币。LLM 闭卷判断用的是平均场规则（等价于早期/典型信号）；翻转题的定义就是"早期信号与终局相反"。要解翻转题必须算**后期动力学**——这正是谱滤波/替身模拟能给出的（我们在 dataflip 上 spiral 10/10、mvar 9/10，说明一部分翻转确实可算；tabular/univar 的翻转由 rich 动力学反转，0/9 与 1/10，是理论边界）。

## 3. RL 思维链坍缩与语义漂移（郭绍阳）

**现象**：Qwen3.5-0.8B RL 训练后 reward 涨但思维链退化成套话/不思考（response length → 16），或语义脱锚（自造词、"fitting less fit"）。

**与本理论的关系（部分相关，超出当前范围）**：这是 RLHF/RL 训练的 collapse 现象，不是"拟合确定性函数"的设定。可以定性映射：reward hacking = 在策略空间里沿 reward 的捷径方向走（类似"训练误差 0 但验证差"的策略版）；思维链压缩 = 截断惩罚下的最小描述长度偏置。严格化需要策略梯度的动力学理论，**不在本目录范围**，标 open。

## 4. KB 积累实验（任梓瑞复现、郭绍阳 3-phase）

**现象**：KB 注入提升 6–14pt，baseline 越低提升越大；PUCT 探索项不如纯 credibility 排序（探索项让未验证假说持续上屏）。

**解释（部分解释）**：

- "baseline 越低 KB 越值钱" = 先验与数据的替代关系：弱模型缺先验，KB 补上的是 $A$（假设类收窄）与 $I$（隐式偏置方向）；强模型自带先验，KB 边际递减。这是标准的"先验×数据"权衡，可用 01 的四分解语言陈述。
- PUCT < 纯 credibility：探索项相当于在未验证假设上加均匀先验权重 → 有效 KB 噪声变大；纯 credibility = 后验加权。这是贝叶斯 vs 探索奖励的经典权衡，不是新物理。
- 这些观察**不改变理论的误差会计**；它们是"知识工程"层的效率现象。

## 5. 与「解题器」直接相关的数字对照

| 方法 | main 500 | dataflip 49 | 性质 |
|---|---|---|---|
| 最强 LLM 闭卷（GPT-5.6 Sol） | 77.6% | — | 经验知识 |
| 10% 截断基线（实测） | 79.4% | 44–53% | 早期信号 |
| **本目录理论答题器（零拟合）** | **83.2%** | **49.0%** | 初始化 + 协议复刻 |

读法：理论答题器在 main 上超过所有 LLM 闭卷和早期截断基线；在 dataflip 上与截断基线持平（都难）。**"理论 vs 知识"的分工**：理论算得出动力学（含一部分翻转），知识（KB/LLM）给的是平均场方向。二者正交，可组合。
