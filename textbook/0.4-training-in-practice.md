## 1. 一道 v1.5 题的题面长什么样

以 `07` §2 的 `q_11b94d` 为例，把每个字段拆开：

- 族          `univar`
- 目标        $f(x)=\tanh(2x)^{3}+\sin(2\pi x)$，$x\in[0,1]$ 均匀采样
- 训练点      $n=256$        测试点 $m=256$
- 标签        $y=f(x)$ 精确值（无噪声）
- 预算        256 steps × batch 16
- 优化器      `AdamW`，`lr = 3e-5`，`wd = 1e-5`，`beta1 = 0.9`
- 损失        MSE
- 候选 A      `depth=4, width=256, act=leaky_relu, layer_norm=FTTF`        → 264,961 参数
- 候选 B      `depth=4, width=256, act=relu, residual=True, layer_norm=TFTT` → 265,473
- 候选 C      `depth=5, width=192, act=leaky_relu, layer_norm=FTTTT`        → 187,393
- 指标        `mean_metric`（10 seeds 均值）、`std_metric`（10 seeds 标准差）
- 答案        C；实测 0.000223 vs A 0.003564 vs B 0.003646

**读题的第一动作不是想架构，是把这五个数抄下来**：`n`、`m`、`T`、`batch`、`(optimizer, lr)`。正文 `07` §1 的"通用动作序列"第 1–2 步就是这个。

## 2. 训练循环解剖

所有 v1.5 题跑的都是同一个骨架（**这是骨架，不是可直接运行的脚本**：`Model`/`criterion`/`evaluate` 由题库 runner 提供。要看真能跑的版本去 `../verification/theory_answerer.py`）：

```python
torch.manual_seed(seed)                 # ← 随机数流的起点
model = Model(spec)                     # ← 消耗随机数：初始化权重
opt   = Optimizer(model.parameters(), **opt_cfg)

for step in range(steps):               # ← T，预算
    idx = torch.randint(0, n, (batch_size,))   # ← 每步一次，形状 (bs,)
    x, y = X[idx], Y[idx]
    opt.zero_grad()
    loss = criterion(model(x), y)
    loss.backward()
    opt.step()

metric = evaluate(model, X_test, Y_test)   # ← 测试集固定，不重采样
```

**三件 `09` 章必须复刻的事**，全部藏在这段代码里：

1. `manual_seed(seed)` 之后**随机数流是连续的**：初始化消耗多少随机数，决定了后面 minibatch 序列是什么。所以替身必须用**同一个模型类**初始化（消耗同样多的随机数），才能拿到同一条 `idx` 序列。
2. `torch.randint(0, n, (bs,))` **每步调用一次、形状 `(bs,)`**，不多不少。多调一次，后面全部错位。
3. 优化器建在**真实参数 $\theta$** 上，不是位移 $d=\theta-\theta_0$ 上。weight decay 作用在 $\theta$，建错对象 `wd` 的含义就变了（`09` §3 Step 3 的第一条警告）。

`seed` 的作用范围：初始化 + minibatch 序列 + （若有）dropout。**10 个 seed = 10 条独立的随机数流**，这是 `0.3` §3 里 $s/\sqrt{10}$ 那个标准误的来源。

## 3. 预算口径：`T`、`batch`、epoch

| 量 | 含义 | `q_11b94d` 的值 |
|---|---|---:|
| `T`（steps） | 参数更新次数 | 256 |
| `batch_size` | 每次更新看几个点 | 16 |
| $T\times\mathrm{batch}$ | **总共看过的样本数** | 4096 |
| epoch | $T\times\mathrm{batch}/n$ | 4096/256 = **16** |
| $n$ | 训练点数 | 256 |

**正文一律用 `T`（步数）当预算，不用 epoch。** 原因是 `0.2` §6：所有收敛公式里出现的是 $T$ 和 $\eta$（$\tau_j=1/(\eta\lambda_j)$、可学窗口 $\eta\lambda_j T\gtrsim 1$），epoch 不进公式。

**注意有放回抽样**：`torch.randint` 是**有放回**的，所以"16 个 epoch"并不意味着每个点被看了 16 次。期望上"至少被看过一次"的点数是 $n\left(1-e^{-T\cdot\mathrm{bs}/n}\right)$；本例 $T\cdot\mathrm{bs}/n=16$，$e^{-16}\approx 1.1\times 10^{-7}$，覆盖率几乎是 100%，但**每个点被抽到的次数极不均匀**。这在理论上意味着每步的 $A_{\mathrm{mat}}$ 是随机的（`0.2` §6.5），也是 $F$ 的训练侧来源。（若 $T\cdot\mathrm{bs}/n$ 只有 1–2，覆盖率掉到 63–86%，漏点效应会变成主要问题；v1.5 各族的比值都在 10 以上，不属于这种情况。）

**为什么"短预算"是这套题的主线**：`T = 256`、`lr = 3e-5`。用 `0.2` §6.4 的语言说，$\eta\lambda_j T$ 里的 $\eta T=3\times 10^{-5}\times 256=7.7\times 10^{-3}$——**除非 $\lambda_j>130$，否则所有模式都没学到**。这就是 `03` §1 说"很多题看起来像架构比较，实际上是优化速度比较"的量化版本。

## 4. 优化器族：更新规则与"有效步长"

### 4.1 五个优化器的更新规则

记 $g_t$ 为第 $t$ 步的梯度。

**SGD**

$$
\theta\leftarrow\theta-\eta g_t
$$

**SGD + momentum**（$m$ 是动量系数，v1.5 里那一栏 `0.9` 或 `0`）

$$
v\leftarrow m\cdot v+g_t;\qquad\theta\leftarrow\theta-\eta v
$$

稳态放大倍数 $\approx 1/(1-m)$；$m=0.9$ → **10 倍**。

**Adagrad**

$$
G\leftarrow G+g_t^{2};\qquad\theta\leftarrow\theta-\eta\, g_t/(\sqrt{G}+\varepsilon)\qquad\text{（逐坐标，平方）}
$$

$G$ **只增不减** → 步长随 $t$ 衰减如 $\eta/\sqrt{t}$ → 累积位移 $\approx 2\eta\sqrt{T}$。**自归一化**，对 `lr` 的敏感度远低于 SGD。

**RMSprop**

$$
v\leftarrow\beta v+(1-\beta)g_t^{2};\qquad\theta\leftarrow\theta-\eta\, g_t/(\sqrt{v}+\varepsilon)
$$

用指数滑动平均代替累加 → 步长**不衰减**，每步位移 $\approx\eta$。

**Adam / AdamW**

$$
\begin{aligned}
m&\leftarrow\beta_1 m+(1-\beta_1)g_t;\qquad v\leftarrow\beta_2 v+(1-\beta_2)g_t^{2}\\
\hat{m}&=m/(1-\beta_1^{t});\qquad\hat{v}=v/(1-\beta_2^{t})\qquad\text{（偏差修正）}\\
\text{Adam}:\quad&\theta\leftarrow\theta-\eta\,\hat{m}/(\sqrt{\hat{v}}+\varepsilon)\\
\text{AdamW}:\quad&\theta\leftarrow\theta-\eta\left[\hat{m}/(\sqrt{\hat{v}}+\varepsilon)+\mathrm{wd}\cdot\theta\right]\qquad\text{（解耦权重衰减）}
\end{aligned}
$$

$\hat{m}/\sqrt{\hat{v}}$ 的量级是 $O(1)$（分子分母同尺度），所以**每步位移 $\approx\eta$**，几乎与梯度大小无关。

### 4.2 有效步长对照表（本章最该记住的一张表）

| 优化器 | 单步位移量级 | 累积位移（$T$ 步） | 对 `lr` 数值的敏感度 |
|---|---|---|---|
| SGD | $\eta\cdot\lVert g\rVert$ | $\eta\cdot\lVert g\rVert\cdot T$（若梯度不衰减） | **极高**：取决于 $\lVert g\rVert$ |
| SGD+momentum(0.9) | $10\cdot\eta\cdot\lVert g\rVert$ | 同上 ×10 | 极高 |
| Adagrad | $\approx\eta/\sqrt{t}$ | $\approx 2\eta\sqrt{T}$ | 中（自归一化） |
| RMSprop | $\approx\eta$ | $\approx\eta T$ | 低 |
| Adam/AdamW | $\approx\eta$ | $\approx\eta T$ | 低 |

### 4.3 这张表直接解释了 `07` §4 的 `q_12016f`

三个候选，`T = 512`：

| 候选 | 优化器/lr | 累积位移量级 | 实测 CE |
|---|---|---|---:|
| A | Adagrad 3e-5 | $2\times 3\times 10^{-5}\times\sqrt{512}\approx 1.4\times 10^{-3}$ | 0.7221 |
| B | AdamW 3e-3 | $3\times 10^{-3}\times 512\approx 1.5$ | **0.03298** |
| C | SGD 3e-5 | $3\times 10^{-5}\times\lVert g\rVert\times 512$，$\lVert g\rVert$ 还很小 | 0.6993 |

**B 的有效位移比 A/C 大三个数量级。** 这不是"B 的架构更好"（A/B 都是 `d2 w16`，参数量 690 vs 626），是 A/C 根本没走。正文 `07` §4.4 说"把 A/C 的结构分析得再细，也救不了它们没走几步的事实"——上面就是那个"几步"的定量版。

**跨优化器不能直接比 `lr` 数值**（`03` §2 的结论）就是这么来的：`3e-5` 对 Adam 是"偏小但能走"，对 SGD 是"基本不动"。

## 5. weight decay $\neq$ L2 正则

| | 在损失里加 $(\lambda/2)\lVert\theta\rVert^{2}$ | AdamW 的 `wd` |
|---|---|---|
| 实现 | 梯度多一项 $\lambda\theta$，然后被 Adam 的 $\sqrt{\hat{v}}$ 归一化 | 直接 $\theta\leftarrow\theta-\eta\cdot\mathrm{wd}\cdot\theta$，**绕过**自适应缩放 |
| 效果 | 大梯度的坐标被衰减得少（被 $\sqrt{\hat{v}}$ 压掉） | 所有坐标按同一比例收缩 |
| 名字 | L2 正则 | 解耦权重衰减（decoupled） |

`06` §5.3 (3) 的关键观察——**weight decay 就是平滑**：$\theta\leftarrow\theta(1-\eta\cdot\mathrm{wd})$ 把 logits 往 0 拉，而 $\mathrm{softmax}(0)=\text{均匀分布}$。所以 wd 把预测往均匀分布拉，正是多项分布估计里的平滑（`0.3` §8.4 提到的一阶公式失效时缺的那一项）。实测：`wd = 1e-3` 时收敛超额 0.0705 nats，比最优平滑的地板 0.0401 多花 76%。

**读题时看到 wd，先想"这是平滑强度"，不要只想"这是正则化"。**

## 6. 架构字段：`depth` / `width` / `act` / `residual` / `layer_norm`

### 6.1 字段口径（v1.5 候选库）

| 字段 | 取值 | 含义 |
|---|---|---|
| `depth` | 1–5 | **隐藏块个数**（不含输入投影与输出投影） |
| `width` | 16, 24, 32, 48, 64, 96, 128, 192, 256 | 每个隐藏块的维度 $W$ |
| `act` | silu, leaky_relu, relu, gelu | 激活函数（`0.2` §9 有导数表） |
| `residual` | True/False | 每个隐藏块是否加恒等通道 $x+\mathrm{block}(x)$ |
| `layer_norm` | 长度 = `depth` 的 T/F 字符串 | **逐层开关**；`FTTF` = 第 2、3 块加 LN |
| `in_dim` | 1, 2, 3, 4, 5, 8, 16 | 输入维度 |
| `out_dim` | 1（回归）/ 2（分类） | 输出维度 |

所以一个 `depth=4` 的 MLP 实际有 **6 个线性层**：`in→W`，然后 4 个 `W→W`，然后 `W→out`。`layer_norm` 字符串只覆盖中间那 4 个块。

### 6.2 参数量公式（本章最实用的一条）

$$
\begin{aligned}
p=\;&(\mathrm{in\_dim}\times W+W) &&\text{输入投影}\\
&+\mathrm{depth}\times(W^{2}+W) &&\text{隐藏块}\\
&+(W\times\mathrm{out\_dim}+\mathrm{out\_dim}) &&\text{输出投影}\\
&+(\#\mathrm{T}\ \text{in}\ \mathrm{layer\_norm})\times 2W &&\text{每个 LN 有 }\gamma,\beta\text{ 两个 }W\text{ 维向量}
\end{aligned}
$$

**`residual` 加 0 个参数**（$x+\mathrm{block}(x)$ 不引入新权重）。

### 6.3 验算（8 个真实候选，全部精确匹配）

| 题 | 候选 | 配置 | 公式算出 | 题库给出 |
|---|---|---|---:|---:|
| q_11b94d | A | d4 w256 LN=FTTF(2T) in1 out1 | $512+4\times 65792+257+2\times 512$ = **264,961** | 264,961 ✓ |
| q_11b94d | B | d4 w256 res LN=TFTT(3T) | $512+263168+257+3\times 512$ = **265,473** | 265,473 ✓ |
| q_11b94d | C | d5 w192 LN=FTTTT(4T) | $384+5\times 37056+193+4\times 384$ = **187,393** | 187,393 ✓ |
| q_aef977 | A | d5 w192 LN=FTTFT(3T) | $384+185280+193+3\times 384$ = **187,009** | 187,009 ✓ |
| q_aef977 | B | d4 w256 res LN=FTTF(2T) | **264,961** | 264,961 ✓ |
| q_aef977 | C | d2 w256 LN=TF(1T) | $512+2\times 65792+257+512$ = **132,865** | 132,865 ✓ |
| q_12016f | A | d2 w16 LN=TT(2T) in2 out2 | $48+2\times 272+34+64$ = **690** | 690 ✓ |
| q_12016f | C | d4 w16 LN=TFFF(1T) in2 out2 | $48+4\times 272+34+32$ = **1,202** | 1,202 ✓ |

**为什么值得学这个**：

1. 30 秒就能验算题面数字有没有抄错（`TFTT` 是 **3** 个 T 不是 2 个——很容易数错，我第一遍就数错了）；
2. 能反推题面没写的字段（比如从 `q_12016f` 的 690 反推出 $\mathrm{in\_dim}=2$）；
3. **能立刻看出"参数量差一个数量级"和"深度差一层"是两件事**：`q_11b94d` 的 A 和 B 参数量只差 512（一个 LN），结构却不同（激活 + 残差 + LN 位置）；而 C 少了 7.7 万参数却赢了。这正是 `01` §5 "参数个数不是容量" 的具体例证。

### 6.4 LayerNorm 与残差各自解决什么

| 组件 | 机制 | 主要影响 |
|---|---|---|
| **LayerNorm** | 对每个样本在特征维上归一化到零均值单位方差，再乘 $\gamma$ 加 $\beta$：$\mathrm{LN}(h)=\gamma\cdot(h-\mu)/\sigma+\beta$ | 阻止逐层尺度漂移 → 改善核的条件数 → 改 $O$（`05` §5 表） |
| **残差** | $h\leftarrow h+\mathrm{block}(h)$，提供恒等通道 | 深层梯度有"高速公路" → 改善条件数 → 改 $O$；同时让 $J$ 里有一个不衰减的项 |

两者是**替代关系**（`05` §5 表的最后一列写了"与 LN 有替代关系"）：都是在对抗深网的信号/梯度衰减。所以 `LN=FTTTT`（4 个 LN，无残差）和 `LN=FTTF`（2 个 LN，有残差）可能达到类似的条件数——这也是 `q_11b94d` 里 A/B/C 三者难以单因素归因的原因。

**注意 `layer_norm` 的逐层性**：`FTTF` 与 `TFTT` 都是"2–3 个 LN"，但**位置不同**。候选库里有 62 种组合（`../notes/bank-audit.md`）。位置影响的是"归一化发生在残差前还是后"（pre-LN vs post-LN），这在深网里是显著的差别。

## 7. 序列模型词汇（bigram 族）

| 术语 | 含义 | `q_235e7e` 的值 |
|---|---|---:|
| `vocab` / $V$ | 词表大小 | 32 |
| `ctx` / $L$ | 上下文长度（一条序列多少 token） | 16 |
| 训练序列数 | 800 | |
| 训练 token 数 $N$ | $800\times\mathrm{ctx}$ | ≈ 12,800 |
| `d_model` | 隐藏向量维度 | A/C: $32/64$，B: $64$ |
| `d_ff` | Transformer FFN 中间维度 | A: 256，C: 64 |
| `logits` | softmax 之前的 $V$ 维实向量 | |
| `embedding` | token → `d_model` 向量的查表 | $V\times \mathrm{d\_model}$ 参数 |

**两个架构的差别**：

- **Transformer 层** = 多头自注意力 + FFN，带残差和 LN。注意力让位置 $t$ 能看到 $1\ldots t$ 所有 token。
- **GRU** = 循环网络，维护一个隐藏状态 $h_t$，$h_t$ 由 $h_{t-1}$ 和当前 token 更新。

**为什么 `07` §5.3 说"B 的 GRU 更匹配一阶马尔可夫结构"**：目标是 bigram，即 $P(y_t\mid y_{t-1})$ **只依赖前一个 token**。注意力提供的"看全部历史"能力在这里是**多余的自由度**——多余自由度意味着更大的有效容量、更慢的收敛、更多要估的参数。GRU 的结构先验正好是"压缩历史进一个状态"，与目标结构匹配。这是 `05` §1 "架构改的是 $A$/$I$/$O$ 三件事的匹配度，不是容量大小" 的实例。

**秩瓶颈**（`0.3` §8.3 讲过的 `06` §5.3 (4)）：输出 logits 矩阵 $V\times V$ 的秩 $\leq \mathrm{d\_model}+1$。$V=48$、$\mathrm{d\_model}=32$ 时 $33<47$ → 有 $A$ 项损失 0.01–0.024 nats。**看 `d_model` 和 $V$ 的关系就能预判这个瓶颈**，不需要训练。

## 8. 指标口径与"瞎猜基线"

### 8.1 三种损失

| 任务 | 损失 | 公式 | 单位 |
|---|---|---|---|
| 回归（univar/mvar） | MSE | $\mathrm{mean}((\mathrm{pred}-y)^{2})$ | 目标量纲的平方 |
| 分类（tabular/spiral/xor） | CE | $-\mathrm{mean}(\log\mathrm{softmax}(\mathrm{logits})[y])$ | nats |
| 语言模型（bigram） | CE | 同上，逐 token 平均 | nats |

**一律是"越低越好"**，答案 = 三个候选里 `mean_metric` 最小的那个。

### 8.2 瞎猜基线（30 秒 sanity check）

这是读题时最该做的第一件事——**先算"什么都没学会"会得多少分**：

| 任务 | 瞎猜基线 | 公式 |
|---|---|---|
| 回归 MSE | 测试集上 $\mathrm{Var}(f)$ | 预测常数值 = 均值 |
| 二分类 CE | $\ln 2=0.6931$ nats | 预测均匀 (0.5, 0.5) |
| $V$ 词表 LM CE | $\ln V$ nats | 预测均匀分布 |

### 8.3 用基线读 `07` 的四道题

| 题 | 候选分数 | 基线 | 读数 |
|---|---|---|---|
| `q_11b94d` | A 0.00356 / B 0.00365 / C 0.000223 | 初始 MSE 0.33–1.08（≈ $\mathrm{Var}(f)$） | 三个都学到了，但 C 多学了一个数量级 |
| `q_12016f` | A 0.7221 / B 0.0330 / C 0.6993 | $\ln 2=0.693$ | **A、C 就在瞎猜线上**（甚至略高于它）→ 完全没学会；B 学到了 |
| `q_144ad6` | A 0.164 / B 0.673 / C 0.677 | $\ln 2=0.693$ | B、C 在瞎猜线上；只有 A 学到了 |
| `q_235e7e` | A 3.582 / B 3.470 / C 3.579 | $\ln 32=3.466$；地板 3.196 | **B 几乎就在均匀预测线上，A/C 还高于它**；可用空间 3.466→3.196 共 0.27 nats，三个候选拿到的都 $\leq 0$ |

**`q_235e7e` 这一行值得停下来看**。这里有三个参照点：

- 均匀预测        $\ln 32=3.4657$ nats
- 预测边缘分布    $H(Y)\in[3.196,3.466]$（未知，取决于转移矩阵的边缘）
- 不可约地板      $H(Y\mid X)=3.196$  nats

候选分数减去均匀线（正数才算"学到了东西"）：

- B: $3.466-3.470=-0.004$      ≈ 0，几乎等于均匀预测
- A: $3.466-3.582=-0.116$      比均匀预测还差
- C: $3.466-3.579=-0.113$      同上

也就是说 512 步 × 16 的预算下，**三个模型基本没吃到 bigram 的条件信息**，连"先学会输出边缘分布"这一步都没走完（A/C 甚至还没到均匀水平）。这直接印证 `06` §5.3 (5) 的结论——实测超额中位数 0.296 nats ≈ 估计地板 0.039 nats 的 7.6 倍，**$O$ 项压倒性主导**。也解释了为什么这题的候选差距（0.11 nats）相对 $s=0.00982$（正文 `04` §5.2）虽然显著，但绝对量很小：所有候选都挤在起跑线附近。

**这就是为什么"瞎猜基线"是必需品**：不做这一步，你会以为 3.47 vs 3.58 是"两个都不错的模型之间的细微差别"，实际上是"三个都没起步的模型，其中一个恰好抖到了均匀线上"。

### 8.4 `std_metric` 的用法

题库给的是 10-seed 的**标准差** $s$，不是标准误。$\mathrm{SE}=s/\sqrt{10}$（`0.3` §3.1）。正文 `04` §5.2 给了各族的 $s$ 中位数——直接除以 3.162 就是 `SE`。

## 9. 怎么在 30 秒内读完一道题

1. 抄五个数：$n$, $m$, $T$, batch, (optimizer, lr)
2. 算瞎猜基线：$\mathrm{Var}(f)$ 或 $\ln C$ 或 $\ln V$
3. 把三个候选的分数和基线比 → 谁根本没学会？（常常一下淘汰 1–2 个）
4. 算有效步长：Adam/RMSprop → $\eta T$；SGD → $\eta T\lVert g\rVert$；Adagrad → $2\eta\sqrt{T}$
   三者相差几个数量级 → $O$ 主导，不用看架构
5. 只有过了第 3、4 步还没分出胜负，才去比架构（→ 0.5/0.6 的工具）
6. 最后查配对显著性：$\lvert\Delta\rvert>2.26\times\mathrm{SE}_{\Delta}$ 吗？（→ 0.3 §4）

**这个顺序不是随意的**：它按"信息量/成本比"排列。第 3 步只要一次减法，第 4 步只要一次乘法，第 5 步要算核谱。正文 `00-cheatsheet` §5 的 60 秒流程是同一个东西的更细版本。

## 10. PyTorch 侧的实操注意（给要跑 `09` 章的人）

| 事项 | 说明 |
|---|---|
| `torch.manual_seed(seed)` | 必须在**建模之前**调用；建模会消耗随机数 |
| `flatten(model.parameters())` | 把所有参数摊成一个 $p$ 维向量；**顺序要固定**（`parameters()` 的顺序由模块注册顺序决定，同一份代码里是稳定的） |
| `torch.func.jacrev` | 反向模式，一次给出整个 $J$；仅当 $n\cdot C\ll p$ 时用（`0.2` §4.2） |
| `torch.func.jvp` | 前向模式；**GRU 等算子不支持**，会报错 → 改有限差分 |
| `torch.autograd.grad(outputs, inputs, grad_outputs=g)` | 算 $J^{\top}g$（VJP），一次反向，精确 |
| 内存 | $J$ 是 $(n\cdot C)\times p$；2048 × 33万 float32 ≈ 2.7 GB。要么放宽上限，要么把测试侧子采样到 256–512 点（`09` §3 Step 2） |
| dtype | 谱分析一律 float64（`0.1` §10 的坑 2）；替身训练可以 float32 |
| `torch.randint(0, n, (bs,))` | 每步一次、形状 `(bs,)`；调用次数和顺序必须与官方一致 |

## 11. 常见坑

| 坑 | 后果 |
|---|---|
| 数错 `layer_norm` 里 T 的个数（`TFTT` 是 3 个） | 参数量对不上，进而怀疑整个题面 |
| 以为 `depth` 是总层数 | 少算 2 个线性层；参数量差一个 $W^{2}$ |
| 以为 `residual=True` 会加参数 | 不加；差别在梯度通路，不在容量 |
| 跨优化器直接比 `lr` 数值 | `03` §2：Adam 的 `3e-5` 和 SGD 的 `3e-5` 差几个数量级 |
| 忘了 momentum 的 $1/(1-m)$ 放大 | $m=0.9$ 时低估 10 倍有效步长 |
| 把 CE 0.699 当"学到了 70%" | 它就是 $\ln 2$ = 瞎猜（§8.3） |
| 把 LM 的 CE 3.47 当"接近地板" | 它等于 $\ln 32$ = 均匀预测；地板是 3.196（§8.3） |
| 把 `std_metric` 当标准误 | 误差棒大 3.16 倍（`0.3` §14） |
| 优化器建在位移 $d$ 上而不是 $\theta$ 上 | wd 的含义变了（`09` §3 Step 3） |
| 复刻训练时 `randint` 多调/少调一次 | 整条 minibatch 序列错位，替身预测失效 |
| 用 epoch 而不是 $T$ 套收敛公式 | 公式里只有 $T$ 和 $\eta$ |
| 看到 $p\gg n$ 就断言过拟合 | `0.1` §5：要看零空间能量；`q_11b94d` 的 $p/n\approx 1000$ 但 C 的测试 MSE 是 0.0002 |

## 12. 一页总结

- 题面五要素：$n$, $m$, $T\times\mathrm{batch}$, (optimizer, lr), loss。先抄下来。
- 参数量 $=\mathrm{in}\times W+W+\mathrm{depth}\times(W^{2}+W)+W\times\mathrm{out}+\mathrm{out}+(\#\mathrm{T}\ \text{in}\ \mathrm{LN})\times 2W$；residual 加 0。
- $\mathrm{depth}=\text{隐藏块数}$，总线性层 $=\mathrm{depth}+2$；LN 是逐层 T/F 开关（数 T 的个数，`TFTT` 是 3 个）。
- 有效步长：Adam/RMSprop $\approx\eta$；SGD $\approx\eta\lVert g\rVert$；Adagrad 累积 $\approx 2\eta\sqrt{T}$；momentum $\times 1/(1-m)$。
- → 跨优化器不能比 lr 数值；有效步长差几个数量级时，$O$ 主导，不必看架构。
- wd 是平滑（把 logits 拉向 0 = 拉向均匀分布），不只是"正则化"。
- 瞎猜基线：回归 $\mathrm{Var}(f)$、二分类 $\ln 2=0.693$、LM $\ln V$。先比基线，常一下淘汰 1–2 个候选。
- GRU 匹配一阶马尔可夫；Transformer 的注意力在这里是多余自由度。logit 矩阵秩 $\leq\mathrm{d\_model}+1$。
- 复刻训练必须对齐：同 seed、同初始化消耗、同 `randint` 调用序列、优化器建在 $\theta$ 上。
