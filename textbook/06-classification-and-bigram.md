# 06 · 分类与语言模型：为什么回归公式不能直接套

> 本章回答：交叉熵（CE）分类和回归（MSE）有什么本质区别？margin 是什么？bigram 语言模型为什么有"熵地板"？这两类题该怎么判断？

---

## 1. 回归 vs 分类：损失不同，理论结构不同

| | 回归（MSE） | 分类（CE） |
|---|---|---|
| 输出 | 实数 | logits / 概率 |
| 损失 | 平方 | 交叉熵 |
| 谱分解 | 有（核/线性区） | **没有**闭式 |
| 隐式偏置 | 最小范数 | 最大 margin（渐近） |
| 有限 $T$ 精确公式 | 核/惰性区有 | **没有** |
| 主要风险 | 优化滞后、aliasing | 边界估计、margin、优化 |

**不要**把回归的 $\sum(1-\eta\lambda)^{2T}a_j^{2}$ 直接套到 CE 上。CE 的动力学是非线性的，有限 $T$ 没有类似闭式。

---

## 2. 分类里"好"是什么意思

分类的验证误差是 0-1 错误率（或 CE）。对二分类：

- 模型输出一个分数/ logit；
- 阈值 0 决定类别；
- 测试误差由**决策边界**的位置和形状决定。

分类版的"谱对齐"可以粗略理解为 **margin**：

> margin = 样本离决策边界的距离（在 logit 空间）

- margin 大：泛化通常更好（在复杂度受控时）；
- margin 小：边界稍微动一点就翻，测试误差对种子敏感。

**max-margin 隐式偏置**：在可分数据上、用 logistic/CE 损失、GD 训练，方向会收敛到最大 margin 解（虽然有限 $T$ 还没完全到）。这解释了为什么分类模型训练久了 logit 范数会一直涨、CE 会一直降，但**准确率/测试误差不一定继续改善**。

## 3. 分类的误差分解

$$
\begin{aligned}
\text{分类误差}\approx{}&A\ \text{（边界表达不了）}\\
&+I\ \text{（}n\text{ 个点估计边界不准 / margin 不够）}\\
&+O\ \text{（}T\text{ 步 margin 还没长够 / 优化没到位）}\\
&+F\ \text{（验证噪声）}
\end{aligned}
$$

### 3.1 tabular：边界复杂度决定 $A$

v1.5 的 tabular 有三种规则：

- `smooth_additive`：边界由光滑加性函数阈值产生 → 浅宽网通常够；
- `sparse_interaction`：边界依赖少量坐标的交互 → 需要一定宽度/深度；
- `piecewise_boundary`：分段边界 → 深度/区域数有优势。

如果边界简单，$A$ 小，胜负往往在 $O$（lr/优化器）；如果边界复杂，$A$ 可能主导。

### 3.2 spiral：深度是边界表达的杠杆

螺旋边界需要"折叠/弯曲"的复合结构：

- 浅网：$A$ 大，怎么调 lr 都难；
- 深网：$A$ 小，但 $O$ 大（条件数/plateau）；
- 短预算：存在预算相关的最优深度。

**spiral 的深度收益主要是 $A$ 的（表达边界），不是"深度本身更好"。**

### 3.3 xor：二阶交互，不需要很深

xor 的目标是少量坐标的符号一致性（二阶交互）：

- 2 层宽网已经能表达；
- 深度不是关键；
- 短预算下胜负通常在 $O$（有效步长）或宽度/优化。

## 4. 三个 v1.5 分类题的实际读法

### 4.1 `q_12016f`（tabular，smooth_additive）

- 候选 A：Adagrad@3e-5；B：AdamW@3e-3；C：SGD@3e-5；
- 实测：B 0.033 ≪ C 0.699 ≈ A 0.722。

**读法**：这是典型的 $O$ 主导。A/C 的 lr/优化器在 512 步内几乎学不动；B 的有效步长大，且 2 层宽 16 对光滑加性边界已足够。**不是"小模型更好"，是"预算内能走到"更重要。**

### 4.2 `q_09e52b`（xor，Adam 3e-4）

- 三个候选都是 4–5 层 MLP，差异在激活/残差/LN 位置；
- 实测 B 0.266 < C 0.381 < A 0.419。

**读法**：xor 不需要深；短预算下 B 的优化/条件数最好。深度差异主要是 $O$，不是 $A$。

### 4.3 `q_144ad6`（spiral，Adagrad）

- A：Adagrad@3e-3，4 层；B/C：Adagrad@3e-5，2/3 层；
- 实测 A 0.164 ≪ B 0.673 ≈ C 0.677。

**读法**：A 的有效步长远大于 B/C；同时 4 层提供螺旋边界所需的 $A$。**先比 $O$，再比 $A$。**

## 5. bigram：不是确定性函数，有熵地板

v1.5 的 bigram 目标是：

- 一个固定的随机 bigram 转移矩阵 $P(y\mid x)$；
- 训练/测试序列按这个矩阵采样；
- 交叉熵有不可约下界：

$$
H(Y\mid X)=\sum_x\pi(x)\,H(P(\cdot\mid x))
$$

v1.5 实测：$H(Y\mid X)$ 在 2.281–3.604 nats；候选 CE/地板 ≈ 1.02–1.57。

**这意味着：**

1. 任何模型都不能把 CE 降到地板以下；
2. 候选差异是"地板之上"的估计/优化误差，通常只有 0.1–0.4 nats；
3. 不能套"无标签噪声回归"的公式；也不能用 $p>n$ 解释一切（token 口径 $n$ 是 9600–19200，$p/n$ 只有约 5）。

### 5.1 bigram 的 $n$ 有三种口径

- 800 条序列（$p/n$ 中位数 ≈ 85）；
- $800\times\mathrm{ctx}$ ≈ 9600–19200 个 token 标签（$p/n$ 中位数 ≈ 5.5）；
- 有效独立样本量（窗口重叠/马尔可夫依赖）介于两者之间。

**讨论 $p/n$ 时必须声明用哪个 $n$。**

### 5.2 `q_235e7e`（bigram，SGD 1e-3）

- A：4 层 TF，d_model=32；B：2 层 GRU，d_model=64；C：3 层 TF，d_model=64；
- 实测：B 3.470 < C 3.579 ≈ A 3.582；地板 3.196。

**读法**：候选差异是地板之上的约 0.27–0.39 nats。B 的 GRU 更匹配"只看当前 token"的一阶马尔可夫结构，SGD 下优化更有效。**不是"参数多/少"决定的。**

### 5.3 地板之上能算多少（2026-10-20 新结果）

bigram 是本项目第一个把 $H+A+I+O(T)+F$ 全部分解开的非回归族。完整推导和验证脚本见 `notes/bigram-estimation.md` 和 `verification/bigram_estimation.py`；这里只给结论。

**(1) 恒等式（严格）**：对任何训练好的模型 $\hat{p}$，

$$
\text{test }\mathrm{CE}=H(Y\mid X)+\sum_x\pi(x)\cdot\mathrm{KL}(P(\cdot\mid x)\,\Vert\,\hat{p}(\cdot\mid x))+F
$$

$F$ 是测试集抽样噪声，期望 0，sd ≈ ±0.013 nats（3200 个测试 token；马尔可夫链的混合膨胀实测约等于 1，可直接当独立样本算）。注意：$F$ 和"估计地板"一样大——但三个候选共用同一份测试集，配对比较时 $F$ 大部分抵消。

**(2) 估计地板 $I$（可算）**：bigram 的"识别问题"就是 $V$ 个独立多项分布的估计。用 $n$ 个样本估计一个 $V$ 面骰子，test $\mathrm{CE}$ 的超额一阶公式是

$$
I\approx(V-1)/(2\cdot\text{每面平均样本数})
$$

对 bigram：每个 context 平均有 $N/V$ 个样本（$N=800\times\mathrm{ctx}$ 个训练 token），所以

$$
I\approx V(V-1)/(2N)
\qquad\text{（一阶公式；}V\leq 32\ \text{时误差 2\% 以内）}
$$

v1.5 全族的地板在 0.014–0.117 nats。$V=48$ 且转移矩阵很"尖"（alpha=1.4）时一阶公式高估约 35%，需要用逐格二项期望精确算（脚本里做了，和模拟完全一致）。这个率是 minimax 的：没有任何估计量能一致地比它低；又因为题库的转移矩阵行与行独立生成（没有低秩结构可利用），Transformer/GRU 也不能靠"跨 context 共享"绕开它。

**(3) 优化项 $O$（查表模型可证，网络部分 open）**：如果模型就是一张 softmax 查表，损失逐 context 解耦且凸，GD 有标准的 $1/T$ 收敛界（数值验证：界在每一步都成立；中段确实是 $\sim 1/T$ 衰减；最早有约 50 步的"从均匀出发"启动平台）。查表模型是 bigram 里条件最好的模型，它的收敛时间是这族题的优化时间下界。两个有直接实战意义的发现：

- **weight decay 就是平滑**。wd 把 logits 往 0 拉，等价于把概率往均匀分布拉。wd=1e-3 时收敛超额 0.0705，比最优平滑的地板 0.0401 多花 76%——wd 太大会直接抬高地板之上的落点。
- **没有 wd 且存在没见过的 $(x,y)$ 格时**，GD 会把那些 logits 永远压下去，test $\mathrm{CE}$ 对 $T$ 呈 U 形（先降后升），早停是必需的。

**(4) 瓶颈 $A$（小但非零）**：模型的 logit 矩阵秩 $\leq\mathrm{d\_model}+1$，而通用转移矩阵需要秩 $V-1$。只有 $V=48$ 且 $\mathrm{d\_model}=32$ 的候选被咬，量级 0.01–0.024 nats——比地板小，但在刀刃题里可能翻盘。

**(5) 全族对照（300 个真实候选）**：

- 地板中位数        0.039 nats
- 实测超额中位数    0.296 nats（≈ 地板的 7.6 倍 → $O$ 主导）
- 低于地板的候选    0 / 300（地板没有被违反 ✓）
- 最优候选          超额的 1.36 倍于地板（已贴近信息极限）

**一句话**：bigram 题的"地板 + 估计 + 测量噪声"现在可以训练前算出来；大多数候选输在优化（$O$），最优候选已经快顶到信息极限，再改架构的收益被地板封死。

## 6. 分类/语言模型的"怎么做"

1. **确认指标**：MSE 还是 CE；CE 不要套回归谱公式。
2. **确认标签是否随机**：5 族确定性；bigram 有熵地板。
3. **估计 $A$**：边界复杂度/模型类是否能表达；spiral 看深度，xor 看二阶交互，tabular 看规则族。
4. **估计 $O$**：lr/优化器/$T$ 是否够；短预算常见 $O$ 主导。
5. **估计 $I$**：$n$ 个点估计边界是否准；margin 是否足够；有限样本波动。
6. **估计 $F$**：10 seeds/测试集噪声；刀刃题不硬判。
7. **bigram 额外**：先算熵地板，再看候选在地板之上的差距；地板之上的估计项 $V(V-1)/(2N)$ 和测试噪声 sd ≈ 0.013 nats 也能先算（见 5.3）。

---

## 7. 常见坑

| 坑 | 后果 |
|---|---|
| 把回归公式套到 CE | 预测完全失准 |
| 忽略 bigram 熵地板 | 把"地板上的差异"当容量差异 |
| 把训练 CE 一直降当"在变好" | 准确率/margin 可能没变 |
| 用 $p/n$ 解释 bigram | $n$ 的口径不唯一 |
| 把 spiral 的深度收益归因于"深度本身" | 实际是边界表达（$A$） |
| 把 tabular 的胜负归因于架构 | 实际常是 lr/优化器（$O$） |

---

## 8. 一页总结

- 分类：CE 无闭式；margin 是分类版的谱对齐；深度收益主要在 $A$（边界表达）。
- 短预算分类题：先比 $O$（lr/优化器），再比 $A$。
- bigram：目标随机，有熵地板；地板之上的估计项 $I\approx V(V-1)/(2N)$ 可算（0.014–0.117 nats）；
  实测超额的中位数是地板的 7.6 倍 → 大多数候选输在 $O$（优化）；
  wd 是平滑、太大会抬高落点；$\mathrm{d\_model}<V-1$ 有小的秩瓶颈。
- 回归公式不能直接套分类/语言模型。
