## 1. 这套教程的读者起点（展开版）

正文 `README.md` 写的是"有基本线性代数/概率直觉、但不一定学过学习理论"。这句话太粗，展开成可操作的三栏清单：

| 默认你已经会 | 默认你不会（正文里现讲） | 默认你可能不会（本前置教程补） |
|---|---|---|
| 求导、矩阵乘法、求和号 | 学习理论（n-width、Rademacher、稳定性界） | 特征分解 / 零空间 / 条件数在"迭代收敛"里怎么用 |
| 跑通过一次 PyTorch 训练 | 核方法、RKHS、NTK | Jacobian 与一阶泰勒线性化（09 章的"切线性化替身"） |
| 知道训练集/测试集要分开 | double descent、benign overfitting 的机制 | 标准误、配对检验、多重比较的乐观偏差 |
| 会读 `lr=3e-5, steps=256, bs=16` 这种配置 | 逼近论（Barron / Sobolev / 深度分离） | 熵、KL、条件熵与"熵地板" |
| 知道 MSE 和交叉熵是两个损失 | 隐式偏置（min-norm / max-margin） | 优化器族（Adam/AdamW/Adagrad/RMSprop）"有效步长"的差异 |

**结论**：正文真正依赖的前置有五块——**谱线性代数、Jacobian 与梯度流、统计噪声、训练实操词汇、核与 NTK**。第六块（逼近论与信息极限）只影响 05 章能读多深，不影响主线判断；如果你只想会"判读一道题"，0.6 可以跳过。

一个诚实的说明：本前置教程**不是**"线性代数/概率论复习课"。它只讲正文真的用到的那部分，并且每一节都标出"这在正文哪一章承重"。想系统学，去看教材（§7 给了推荐）。

## 2. 30 题自测（答不上就去对应章）

> 六组各 5 题。**每组只做前两题就足以判断自己缺不缺这一章**；想认真定位就全做。

### 组 1 · 线性代数 → `0.1`

1. $\Phi$ 是 $n\times p$ 且 $p>n$。为什么 $\Phi^\top\Phi$ 必有非平凡的零空间？维数至少多少？
2. 实对称矩阵一定能对角化吗？特征向量能选成两两正交的吗？
3. $(I-\eta A)^{T}$ 这个矩阵幂怎么算？为什么必须先换到 $A$ 的特征基里？
4. $\Phi^\top\Phi$（$p\times p$）和 $\Phi\Phi^\top$（$n\times n$）的非零特征值有什么关系？为什么这件事让"$n\times n$ 核矩阵"够用？
5. 条件数 $\kappa=\lambda_{\max}/\lambda_{\min}$ 大，对"迭代 $T$ 步能走多远"意味着什么？
6. "有效秩"和 $p$ 有什么区别？为什么正文说容量不是参数个数？

### 组 2 · 微积分与梯度 → `0.2`

7. $J=\partial g/\partial\theta$ 的形状是什么？$JJ^\top$ 和 $J^\top J$ 各叫什么、各是什么形状？
8. 前向模式自动微分算的是什么量？反向模式算的是什么量？为什么大输出（语言模型）走前向、大参数走反向？
9. 为什么"模型对 $\theta$ 是线性的 + MSE"一定是凸问题？凸在这里买到了什么？
10. $d\theta/dt=-A\theta$ 的解是什么？把它离散化成 $\theta\leftarrow\theta-\eta A\theta$ 后，稳定性条件是什么？
11. $da/dt\propto a^{4/3}\cdot(s-a)$，$a(0)$ 很小，为什么会出现长 plateau？

### 组 3 · 概率与统计 → `0.3`

12. 10 个 seed 的指标均值，它的标准误怎么算？
13. 比较同一道题的两个候选，为什么必须用"配对差"而不是独立样本公式？
14. 交叉熵、熵、KL 三者的关系是什么？为什么 $\mathrm{KL}\ge 0$ 直接给出"熵地板"？
15. 用 $N$ 个样本估计一个 $V$ 面骰子，plug-in 交叉熵为什么会系统性偏高？量级是多少？
16. 反复用同一个验证集挑 $K$ 个模型，为什么会乐观？偏差量级怎么估？

### 组 4 · 训练实操 → `0.4`

17. $\mathrm{steps}\times\mathrm{batch\_size}$ 是什么量？和 epoch 什么关系？为什么正文强调"预算"是 $T$ 而不是 epoch？
18. Adam 和 SGD 在同一个 `lr` 数值下为什么不能直接比？Adagrad 的位移为什么随 $\sqrt{T}$ 长？
19. AdamW 的 weight decay 和"在损失里加 L2"有什么区别？
20. LayerNorm 和残差各自解决什么问题？`layer_norm=FTTF` 这种写法是什么意思？

### 组 5 · 核与 NTK → `0.5`

21. 核函数 $K(x,x')$ 和特征映射 $\varphi(x)$ 是什么关系？
22. NTK 的定义是什么？为什么它就等于 $JJ^\top$？
23. "惰性区（lazy）"是什么意思？怎么用实验检验一个候选是不是惰性的？
24. 谱偏置（spectral bias）说的是哪一件事？可学窗口的判据是什么？
25. 为什么核 GD 的 early stopping 和 ridge 正则"同尺度"（但非精确等价）？

### 组 6 · 逼近论与信息极限 → `0.6`

26. $A=\inf_{g\in G}\lVert f-g\rVert^{2}$ 是什么意思？为什么"加参数"不一定降 $A$？
27. $n^{-s/d}$ 里的 $s$ 和 $d$ 分别是什么？为什么它叫维度诅咒？
28. n-width 给的是哪一类结论（上界/下界/最坏情况）？为什么它能当"地板"？
29. double descent 的第二降段靠什么机制？无标签噪声时为什么这个机制失效？
30. 稳定性界/Rademacher/PAC-Bayes 为什么"方向对但常松"？

## 5. 统一符号表（前置与正文共用）

| 符号 | 含义 | 形状 / 单位 |
|---|---|---|
| $f$ | 目标函数（真值） | 输入域 → 实数或类别分布 |
| $G$ | 表达式类（模型类） | 函数集合 |
| $g_\theta$ | 参数化表达式（模型） | |
| $\theta$, $\theta_0$, $\theta_T$, $\theta^{*}$ | 参数、初始参数、T 步后参数、真参数 | $p\times 1$ |
| $p$ | 参数个数 | 标量 |
| $n$ | 训练点数 | 标量 |
| $m$ | 测试/验证点数 | 标量 |
| $T$ | 训练步数（预算） | 标量 |
| $\eta$ | 学习率（步长） | 标量 |
| $\Phi$ | 训练特征矩阵 | $n\times p$ |
| $A_{\mathrm{mat}}$ | $\Phi^\top\Phi/n$（Gram / 经验核） | $p\times p$ |
| $K$ | 核矩阵 | $n\times n$ |
| $\lambda_j$ | 核/Gram 的第 j 个特征值 | 标量 $\ge 0$，按降序 |
| $\varphi_j$ | 对应的特征函数/特征向量 | |
| $a_j$ | 目标在第 j 个特征方向上的系数 | 标量 |
| $J$ | Jacobian $\partial g/\partial\theta$ | $(n\cdot C)\times p$ |
| $R_{\mathrm{te}}$ | 测试/验证风险 | 与损失同单位 |
| $A$, $I$, $O(T)$, $F$ | 四项分解：近似 / 识别 / 优化 / 波动 | 同上 |
| $H(Y\mid X)$, $\mathrm{KL}$, $\mathrm{CE}$ | 条件熵、KL 散度、交叉熵 | nats |
| $V$, $N$, $\mathrm{ctx}$ | 词表大小、训练 token 数、上下文长度 | 标量 |
| $\mathrm{SE}$ | 标准误 | 与指标同单位 |

**一个符号冲突要先说清楚**：正文里 $A$ 有两个意思——四分解里的 **approximation 项**，以及 $A=\Phi^\top\Phi/n$ 这个 **Gram 矩阵**（见 `01-what-training-is.md` §4.1、`02-exact-case.md` §2.1）。上下文能区分，但本前置教程统一把 Gram 矩阵写成 $A_{\mathrm{mat}}$，避免你在推导里自己搞混。读到正文时记得换回来。

**另一个约定**：$\lambda_j$ 到底有没有除以 $n$，正文各章不完全一致（`02-exact-case.md` §3.1 有一句免责说明）。判据本身（$\eta\lambda_j T\gtrsim 1$）对这个归一化不敏感，但你要做数值预测时必须统一。本前置教程一律用"损失里不带 $1/n$、$\lambda_j$ 是核矩阵 $K$ 本身的特征值"这一套。

## 6. 本前置教程不讲什么

- **不重复正文**。四项分解、可学窗口、刀刃题判据这些正文讲得更好，这里只在需要时引用。
- **不给完整证明**。给的是"能自己推一遍"的骨架 + 直觉 + 反例。要严格证明去看 §7 的教材。
- **不覆盖测度论/泛函分析**。RKHS、Mercer 定理都只给"够用的直觉版本"，不讲可测性、不讲核的正定性刻画细节。
- **不讲 Lean**。`../lean/` 是形式化规格，与本前置无关。
- **不讲元学习/题库采样器**。正文 08 §2.5 说清楚了那是另一类问题。
