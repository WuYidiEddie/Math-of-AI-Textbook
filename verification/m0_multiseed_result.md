# M0 · 多种子收益试点（阴性结果）

> 日期：2026-10-21 ｜ 数据：`theory_answerer.jsonl` 中每族前 8 题 × 3 候选 × seed {0,1,2}
> 问题：答题器只用 seed 0 预测，而官方答案键是 10-seed 均值——预测侧补多种子能不能涨分？

## 结果

| 指标 | 值 |
|---|---|
| 3-seed 完整题数 | 48（每族 8） |
| seed-0-only top-1 | 44/48 = 91.7% |
| 3-seed 均值 top-1 | 44/48 = 91.7% |
| seed0 vs 3-seed 的 argmin 翻转 | **0/48** |
| 单 seed 与 3-seed 均值不一致的 (题,seed) | 3/144 = 2.1% |

## 结论

**预测侧的种子噪声不是瓶颈。** 惰性线性化模拟在固定初始化后没有 minibatch 随机性（复刻的是同一条序列，种子只影响初始化），而初始化对"谁赢"的影响在这组题上为零翻转。多种子的预期收益上限 ≈ 0–2%，不抵 3–10 倍算力成本。**不值得全量跑多种子。**

注意：该子集 top-1（91.7%）高于全量（83.2%）是因为"每族前 8 题"不是随机抽样；此处只有翻转率/不一致率可作决策依据。

## 决策

按 M0–M4 计划：放弃预测侧多种子，转向 **M2（初始化可算的 lazy→rich 漂移计）+ M3（漂移计真实性校验）**——那才是剩下 ~17% 误差的来源（特征学习）。
